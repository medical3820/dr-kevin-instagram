# Privacy Policy — Dr Kevin Shorts Uploader

_Last updated: 2026-10-15_

Dr Kevin Shorts Uploader is a private, internal tool. It is used only by its owner to upload the owner's
own educational videos to the owner's own YouTube channel. It is not offered to the public and no other
person can sign in to it.

## What data it accesses
- **YouTube Data API (scope `youtube.upload`)**: to upload the owner's videos with a title, description,
  tags and a scheduled publish time.
- **YouTube Data API (scope `youtube.readonly`)**: to read the titles of the owner's recent uploads, only to
  avoid uploading the same video twice.

## What data it stores
Only the resulting YouTube video ID, upload time and scheduled publish time, in a text file
(`published_shorts.txt`) in this repository. No personal data of any other user is collected, stored,
sold or shared.

## Credentials
OAuth credentials are kept in encrypted GitHub Actions secrets and are never published.
Access can be revoked at any time at https://myaccount.google.com/permissions .

## Google API Services User Data Policy
Use of information received from Google APIs adheres to the
[Google API Services User Data Policy](https://developers.google.com/terms/api-services-user-data-policy),
including the Limited Use requirements, and to the
[YouTube API Services Terms of Service](https://developers.google.com/youtube/terms/api-services-terms-of-service).
Users of this tool are also bound by the [YouTube Terms of Service](https://www.youtube.com/t/terms)
and the [Google Privacy Policy](https://policies.google.com/privacy).
