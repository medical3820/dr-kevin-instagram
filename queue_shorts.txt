# YouTube Shorts 업로드 대기열 — scripts/publish_youtube.py 가 읽는다.
# ※ Google API 감사 통과 전에는 비워 둔다. 그동안은 YouTube Studio 에서 직접 예약 업로드.
#   (감사 전 API 업로드는 '비공개(잠김)'으로 고정되어 공개되지 않는다 — docs/youtube_setup.md)
#
# 새 쇼츠: shorts/<폴더>/ 에 video.mp4 · short.json 을 넣고 이 파일 맨 아래에 폴더명 추가.
# short.json 예:
#   {"id":"CR06-YT","title":"...","description":"...","tags":["dermatologist","skincare"],
#    "video":"video.mp4","publish_at":"2026-10-20T10:00-04:00","category_id":"27",
#    "made_for_kids":false,"contains_synthetic_media":false}
#   category_id: "27" Education / "26" Howto & Style. publish_at 기본 미 동부 10:00.
# 예약 실행은 publish_at 72시간 전부터 미리 올려 YouTube 가 그 시각에 정확히 공개한다.
# 올린 항목은 published_shorts.txt 에 기록되고 다시 올리지 않는다(같은 제목도 차단).
